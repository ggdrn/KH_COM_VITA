# KH:COM Vita v0.02.02

A native PS Vita port of *Kingdom Hearts: Chain of Memories* (GBA, USA), built on the community
decompilation. The game's code runs natively on the Vita; only the GBA's picture processor is reproduced
in software. Runs at a stable 60 fps.

**This VPK contains no game data.** You need your own dump of the cartridge (see Installation).

## Controls

| Vita | Action |
|---|---|
| D-pad / **left stick** | Move (the analog stick works as the D-pad) |
| Cross / Circle | A / B — swap them with `swap_ab=1` in `config.ini` |
| L / R | L / R |
| **Triangle** | **L + R together**: stock a card / perform a sleight with one button instead of pressing both shoulders |
| **Square** | **Dodge roll** toward the direction you are holding (or the way you face). On the GBA this needs a double tap on the D-pad. Works for Sora and Riku |
| Start | Start. **Skips the movies** (opening and endings) |
| Select | Select |

## Resolution and widescreen

- **Full-screen 16:9 at 960×544.** The game is drawn 282 pixels wide instead of 240, so it fills the Vita's
  screen and **shows more of each scene** instead of stretching it.
- **The scenery continues into the extra space.** The GBA only keeps a 240-pixel window of each map in
  video memory, so the extra columns are drawn from the game's full map data: events, battles and the
  card-built field rooms (e.g. Traverse Town) all extend past the original edges with their real scenery.
- **Characters, enemies, items and effects stay visible in the extra space** instead of vanishing at the
  old screen edge.
- **Menus and UI screens designed for the original screen** (pause and save menus, the door's card
  selection) are shown at their original width with black bars, so nothing breaks at their edges.
- Other display modes in `ux0:data/khcom/config.ini`: `display=fit` (original 3:2 with side bars) or
  `display=stretch`; `filter=linear` or `filter=nearest`.

## HUD improvements

- **Sora's HP display is now also shown while exploring the map**, not only in battle. It shows the real
  current HP, which the game keeps between battles (Riku's in Reverse/Rebirth).
- **In battle the HP display sits a little lower**, so Sora's portrait is no longer cut off at the top of
  the screen.
- **When the pause or save menu is open, the HP display goes behind it** instead of covering the menu.

## Also in this build

- Opening and ending movies play (with sound).
- All music channels play, including the GBA's four "Game Boy" sound channels.
- The save is also written when the Vita suspends, so closing the game right after saving keeps it.
- Many crash fixes (first boss, Pooh's world map, card battles) and graphics fixes (sprite colours).

## Installation

1. **`libshacccg.suprx`** must be at `ur0:data/libshacccg.suprx` (extract it on your own console with
   [this guide](https://samilops2.gitbook.io/vita-troubleshooting-guide/shader-compiler/extract-libshacccg.suprx)).
2. **Recommended:** the [kubridge](https://github.com/bythos14/kubridge/releases) kernel plugin
   (`ur0:tai/kubridge.skprx` under `*KERNEL` in `ur0:tai/config.txt`, then reboot).
3. Install `khcom_us_v0.02.02.vpk` (e.g. with VitaShell).
4. **Copy your own ROM dump** of Kingdom Hearts: Chain of Memories (USA) to `ux0:data/khcom/rom.gba`.
   It must be the unmodified dump, SHA-1 `10729bd884f8fdca7a310b6d606c52e46657aa48`. If it is missing or
   wrong, the game tells you on launch.
5. Launch. Saves go to `ux0:data/khcom/khcom.sav`.

## Known issues

- This is an early release: not every world has been played through yet. If the game crashes, please
  attach `ux0:data/khcom/log.txt` and the `ux0:data/psp2core-*.psp2dmp` file to your report.
