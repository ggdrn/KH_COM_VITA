# KH:COM Vita v0.04.00

**A new options menu, sharper picture, new card controls and a game-over fix. If you are on v0.02.x,
please update:** in earlier versions **the game froze when Sora was defeated**, instead of showing the
Continue screen.

## Fixed

- **The game no longer freezes at game over.** When Sora fell in battle the Continue screen was removed on
  its first frame and the game waited forever for a choice. It now appears and works (Continue / quit).
  The same kind of problem was fixed in the enemy's card animation, where it could make the card vanish.

## New: options menu (Start + L + R)

Press **Start + L + R** at any time to open the port's menu. The game pauses while it is open, and your
choices are saved to `ux0:data/khcom/config.ini`. It has two tabs; switch between them with **L / R**.

### PICTURE

- **Sharp pixels** (on by default): the Vita's screen is 3.4 GBA pixels per pixel, so plain scaling either
  blurs the picture or makes pixels uneven (some 3, some 4 screen pixels wide). Sharp pixels keeps every
  GBA pixel the same size and crisp.
- **GBA colors** (on by default): the GBA's screen was darker and less saturated than the Vita's OLED/LCD,
  and the game's colours were chosen for it. This brings the colours closer to how they looked on the GBA.
- **Smooth edges: Scale3x** (off by default): a pixel-art upscaler that rounds off the stair steps of
  diagonal edges. It runs on the CPU and costs some performance; turn it on if you prefer the look.

The picture changes are visible right away, behind the menu.

### CONTROLS

Every control addition of the port can be turned on or off here (all on by default):

- **Rear touch: clear cards** — see "Return the stocked cards" below.
- **Square: dodge roll**.
- **Triangle: select cards** (L + R).
- **Right stick: cards** — see below.

## New: card controls

- **Right stick for the cards** in battle:
  - **left / right** = L / R: previous / next card,
  - **up** = L + R: stock a card / perform a sleight,
  - **down, held 1 s**: return the stocked cards (below).
- **Return the stocked cards to your hand** (Sora), which the GBA version can't do: **hold the rear touch
  pad, or the right stick down, for 1 second**. A bar under the stocked cards fills up while you hold;
  let go before it is full to cancel. The cards go back to their places in your deck and **the card under
  your cursor stays selected**. It is refused (with a beep) when a room card has changed the stocked cards'
  values, or while a sleight is already under way.

## New: moogle points notice

When Sora picks up moogle points on the map, the **bottom-right corner shows how many you got**
(`+25 MOOGLE POINTS`), then **your total** (`MOOGLE POINTS: 1234`), 3 seconds each. Picking up more in
the meantime adds up. It hides while the pause or save menu is open.

---

A native PS Vita port of *Kingdom Hearts: Chain of Memories* (GBA, USA), built on the community
decompilation. The game's code runs natively on the Vita; only the GBA's picture processor is reproduced
in software. Runs at a stable 60 fps.

**This VPK contains no game data.** You need your own dump of the cartridge (see Installation).

## Controls

| Vita | Action |
|---|---|
| D-pad / **left stick** | Move (the analog stick works as the D-pad) |
| Cross / Circle | A / B — swap them with `swap_ab=1` in `config.ini` |
| L / R | L / R |
| **Triangle** | **L + R together**: stock a card / perform a sleight with one button |
| **Square** | **Dodge roll** toward the direction you are holding (or the way you face). On the GBA this needs a double tap on the D-pad. Works for Sora and Riku |
| **Right stick** | Left / right: L / R (change card); up: L + R; down held 1 s: return the stocked cards |
| **Rear touch pad**, held 1 s | Return the stocked cards to the hand |
| Start | Start. **Skips the movies** (opening and endings) |
| Select | Select |
| **Start + L + R** | **Options menu** |

## Resolution and widescreen

- **Full-screen 16:9 at 960×544.** The game is drawn 282 pixels wide instead of 240, so it fills the Vita's
  screen and **shows more of each scene** instead of stretching it.
- **The scenery continues into the extra space**, drawn from the game's full map data, and characters,
  enemies, items and effects stay visible there.
- **Menus and UI screens designed for the original screen** (pause and save menus, the door's card
  selection) are shown at their original width with black bars.
- Other display modes in `ux0:data/khcom/config.ini`: `display=fit` (original 3:2 with side bars) or
  `display=stretch`.

## HUD

- Sora's HP display is also shown while exploring the map, sits a little lower in battle so the portrait
  isn't cut off, and goes behind the pause and save menus.

## Installation

1. **`libshacccg.suprx`** must be at `ur0:data/libshacccg.suprx` (extract it on your own console with
   [this guide](https://samilops2.gitbook.io/vita-troubleshooting-guide/shader-compiler/extract-libshacccg.suprx)).
2. **Recommended:** the [kubridge](https://github.com/bythos14/kubridge/releases) kernel plugin
   (`ur0:tai/kubridge.skprx` under `*KERNEL` in `ur0:tai/config.txt`, then reboot).
3. Install `khcom_us_v0.04.00.vpk` (e.g. with VitaShell).
4. **Copy your own ROM dump** of Kingdom Hearts: Chain of Memories (USA) to `ux0:data/khcom/rom.gba`.
   It must be the unmodified dump, SHA-1 `10729bd884f8fdca7a310b6d606c52e46657aa48`. If it is missing or
   wrong, the game tells you on launch.
5. Launch. Saves go to `ux0:data/khcom/khcom.sav`. Your existing save and `config.ini` keep working; the new
   options are added to `config.ini` with their defaults.

## Known issues

- Returning the stocked cards works for Sora; Riku (Reverse/Rebirth) is not supported yet.
- *Smooth edges (Scale3x)* can lower the frame rate; it is off by default.
- This is an early release: not every world has been played through yet. If the game crashes, please
  attach `ux0:data/khcom/log.txt` and the `ux0:data/psp2core-*.psp2dmp` file to your report.
