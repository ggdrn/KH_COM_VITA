# KH:COM Vita v0.05.00

**10 save slots, menus that fill the screen, safer saving and a cleaner widescreen picture.**

## Fixed

- **Saves are no longer lost when you close the game right after saving.** The save is now written to
  the memory card within a second of saving, and in a way that survives the app being closed in the middle
  of the write (the next launch finishes it).
- **No more cyan flashes in the widescreen margins** during room transitions and when opening the door's
  card selection. That colour is hidden on the GBA; the margins now stay dark there.
- **The HP display lines up with the card hand** in widescreen (both in the left margin).

## New: 10 save slots

The game has 2 save slots. The port now keeps **5 banks of 2 slots, 10 slots in all**: choose the bank
in the options menu (**Start + L + R → GAME → SAVE BANK**). The game's save and load screens then use that
bank. Switching does not restart the game, so you can also save your current progress into another bank.

- Bank 1 is `ux0:data/khcom/khcom.sav`, the same file as before (your existing save, or one copied from a
  GBA emulator, keeps working). Banks 2–5 are `khcom2.sav` … `khcom5.sav`.
- If the load screen is already open, leave it and come back after switching.

## New: GAME tab in the options menu

The options menu (**Start + L + R**) has a third tab, **GAME**:

- **Field HP display** — show Sora's HP while exploring the map (on by default).
- **Save bank** — see above.
- **Wide menus** (on by default) — the pause and save menus, the status and deck screens and the title's
  load screen were designed for the GBA's narrower screen and used to show black bars. They are now
  stretched to fill the whole 16:9 screen, with even, crisp pixels. Turn it off to get the bars back.

## Widescreen polish

- **Logos and title screen:** the extra space at the sides takes each scene's background colour instead of
  black bars.

---

A native PS Vita port of *Kingdom Hearts: Chain of Memories* (GBA, USA), built on the community
decompilation. The game's code runs natively on the Vita; only the GBA's picture processor is reproduced
in software. Runs at a stable 60 fps.

**This VPK contains no game data.** You need your own dump of the cartridge (see Installation).

## Controls

| Vita | Action |
|---|---|
| D-pad / **left stick** | Move (the analog stick works as the D-pad) |
| Cross / Circle | A / B — swap them with `swap_ab=1` in `config.ini` |
| L / R | L / R |
| **Triangle** | **L + R together**: stock a card / perform a sleight with one button |
| **Square** | **Dodge roll** toward the direction you are holding (or the way you face) |
| **Right stick** | Left / right: L / R (change card); up: L + R; down held 1 s: return the stocked cards |
| **Rear touch pad**, held 1 s | Return the stocked cards to the hand |
| Start | Start. **Skips the movies** (opening and endings) |
| Select | Select |
| **Start + L + R** | **Options menu** (PICTURE, CONTROLS, GAME) |

Every control addition can be turned off in the options menu's CONTROLS tab.

## Also in the port

- Full-screen 16:9 at 960×544 that shows more of each scene, with the scenery continuing into the extra
  space.
- Options menu: sharp pixels and GBA colours (on by default), optional Scale3x smooth edges.
- Return stocked cards to the hand (Sora), with a progress bar under the stock.
- Moogle points notice on the field.
- Sora's HP display also on the map.

## Installation

1. **`libshacccg.suprx`** must be at `ur0:data/libshacccg.suprx` (extract it on your own console with
   [this guide](https://samilops2.gitbook.io/vita-troubleshooting-guide/shader-compiler/extract-libshacccg.suprx)).
2. **Recommended:** the [kubridge](https://github.com/bythos14/kubridge/releases) kernel plugin
   (`ur0:tai/kubridge.skprx` under `*KERNEL` in `ur0:tai/config.txt`, then reboot).
3. Install `khcom_us_v0.05.00.vpk` (e.g. with VitaShell).
4. **Copy your own ROM dump** of Kingdom Hearts: Chain of Memories (USA) to `ux0:data/khcom/rom.gba`.
   It must be the unmodified dump, SHA-1 `10729bd884f8fdca7a310b6d606c52e46657aa48`. If it is missing or
   wrong, the game tells you on launch.
5. Launch. Your existing save and `config.ini` keep working; the new options are added with their defaults.

## Known issues

- Returning the stocked cards works for Sora; Riku (Reverse/Rebirth) is not supported yet.
- *Smooth edges (Scale3x)* can lower the frame rate; it is off by default.
- This is an early release: not every world has been played through yet. If the game crashes, please
  attach `ux0:data/khcom/log.txt` and the `ux0:data/psp2core-*.psp2dmp` file to your report.
