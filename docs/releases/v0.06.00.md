# KH:COM Vita v0.06.00

**Full-width dialogue boxes, cleaner widescreen in cutscenes and boss fights, and an option to skip the
intro.**

## Fixed

- **Boss arenas no longer show black space at their edges.** The battle camera stopped where the GBA's
  narrower screen reached the end of the arena, so the extra widescreen space showed the empty area past
  it. In widescreen the camera now stops a little earlier, and the whole view stays inside the arena.
- **No more leftover bits of the dialogue box at the screen edges** during cutscenes and conversations.
  When closed, the box sits just past the GBA's screen edge, and its frame used to show in the widescreen
  margins.

## New

- **Dialogue boxes fill the 16:9 screen.** Once a box is open it stretches to both edges of the Vita's
  screen: its rounded end and its open side move out to the edges and the frame's pattern fills the gap,
  with no distortion. The text and the portrait stay in place inside it. While the box slides in or out
  it moves as on the GBA.
- **Skip intro** (options menu, **Start + L + R → GAME**, off by default): the game starts straight at the
  title menu (new game / load / continue), without the logos and the title animation. The save check the
  game runs at boot still happens.

---

A native PS Vita port of *Kingdom Hearts: Chain of Memories* (GBA, USA), built on the community
decompilation. The game's code runs natively on the Vita; only the GBA's picture processor is reproduced
in software. Runs at a stable 60 fps.

**This VPK contains no game data.** You need your own dump of the cartridge (see Installation).

## Controls

| Vita | Action |
|---|---|
| D-pad / **left stick** | Move (the analog stick works as the D-pad) |
| Cross / Circle | A / B — swap them with `swap_ab=1` in `config.ini` |
| L / R | L / R |
| **Triangle** | **L + R together**: stock a card / perform a sleight with one button |
| **Square** | **Dodge roll** toward the direction you are holding (or the way you face) |
| **Right stick** | Left / right: L / R (change card); up: L + R; down held 1 s: return the stocked cards |
| **Rear touch pad**, held 1 s | Return the stocked cards to the hand |
| Start | Start. **Skips the movies** (opening and endings) |
| Select | Select |
| **Start + L + R** | **Options menu** (PICTURE, CONTROLS, GAME) |

Every control addition can be turned off in the options menu's CONTROLS tab.

## Also in the port

- Full-screen 16:9 at 960×544 that shows more of each scene, with the scenery continuing into the extra
  space.
- Options menu: sharp pixels and GBA colours (on by default), optional Scale3x smooth edges, wide menus,
  field HP display, skip intro.
- 10 save slots (5 banks of 2), switched from the options menu.
- Return stocked cards to the hand (Sora), with a progress bar under the stock.
- Moogle points notice on the field.

## Installation

1. **`libshacccg.suprx`** must be at `ur0:data/libshacccg.suprx` (extract it on your own console with
   [this guide](https://samilops2.gitbook.io/vita-troubleshooting-guide/shader-compiler/extract-libshacccg.suprx)).
2. **Recommended:** the [kubridge](https://github.com/bythos14/kubridge/releases) kernel plugin
   (`ur0:tai/kubridge.skprx` under `*KERNEL` in `ur0:tai/config.txt`, then reboot).
3. Install `khcom_us_v0.06.00.vpk` (e.g. with VitaShell).
4. **Copy your own ROM dump** of Kingdom Hearts: Chain of Memories (USA) to `ux0:data/khcom/rom.gba`.
   It must be the unmodified dump, SHA-1 `10729bd884f8fdca7a310b6d606c52e46657aa48`. If it is missing or
   wrong, the game tells you on launch.
5. Launch. Your existing saves and `config.ini` keep working; the new option is added with its default.

## Known issues

- Returning the stocked cards works for Sora; Riku (Reverse/Rebirth) is not supported yet.
- *Smooth edges (Scale3x)* can lower the frame rate; it is off by default.
- This is an early release: not every world has been played through yet. If the game crashes, please
  attach `ux0:data/khcom/log.txt` and the `ux0:data/psp2core-*.psp2dmp` file to your report.
